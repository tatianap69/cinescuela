# Proyecto: Cinescuela con PHP

Este proyecto es una página dinámica desarrollada en **PHP**, que consume datos desde la API de Cinescuela (`https://webadmin.cinescuela.org/wp-json/wp/v2/`).  
El objetivo es mostrar información actualizada como carrusel de imágenes, datos estadísticos, películas del mes, ciclos y novedades, todo de forma dinámica.

---

## 🚀 Características
- Uso de **PHP** para consumir datos en formato JSON.
- Diseño responsivo con **Bootstrap 4**
- Navegación principal con íconos SVG.
- Carrusel dinámico que carga imágenes desde la API.
- Sección de estadísticas con datos obtenidos desde la API.
- Listado de **películas del mes** y ciclos.
- Sección de novedades con publicaciones destacadas.

---

## ▶️ Cómo ejecutar el proyecto

1. Clonar el repositorio:  
   ```bash
   git clone https://github.com/tatianap69/cinescuela
   ```
2. Entrar al directorio del proyecto:  
   ```bash
   cd cinescuela
   ```

### 🔹 Servidor embebido de PHP
1. En la terminal del proyecto, ejecutar:

   ```bash
   php -S localhost:8000

2. En el navegador, abrir la URL: http://localhost:8000/index.php
